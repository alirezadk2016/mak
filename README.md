# makvandi.dk

Personal portfolio of **Alireza Makvandi**, IT supporter in Aarhus, Denmark.

Live: [www.makvandi.dk](https://www.makvandi.dk)

## Stack

- React 18 + TypeScript, built with Vite
- Tailwind CSS + Framer Motion
- Self-hosted fonts via Fontsource (GDPR: no external font requests, no cookies, no tracking)
- Hosted on Vercel, deploys automatically from `main`

## How it works

The site is a SPA that gets **pre-rendered to static HTML** for SEO:

- `scripts/prerender.mjs` boots the built app in headless Chromium, captures every route with its final DOM, injects per-route `<title>`/meta/canonical (plus TechArticle + BreadcrumbList structured data on glossary pages) and writes the result to `prerendered/`.
- A small Vite plugin (`vite.config.ts`) overlays `prerendered/` onto `dist/` at build time, so Vercel serves real HTML to crawlers while the same SPA takes over in the browser.
- `.github/workflows/prerender.yml` refreshes the pre-rendered HTML on every push to `main`.
- `sitemap.xml` and `robots.txt` are generated by the same script.

## Scripts

```bash
npm run dev           # local dev server
npm run build         # type-check + production build (overlays existing prerendered/)
npm run build:static  # full pipeline: clean prerendered/, build, re-prerender all routes
```

## Structure

```
src/
  components/   home sections + shared UI (BrandCover, ErrorBoundary, TitleSync, ...)
  pages/        route pages (about, experience, projects, glossary, colophon, 404)
  data/         glossary content (da/en)
  translations.ts  all bilingual copy for the home page
scripts/
  prerender.mjs    SSG pipeline
  build_cv.py      generates public/cv-alireza-makvandi.pdf
public/           static assets, CV, recommendation PDF, sitemap, manifest
prerendered/      committed static HTML (rebuilt by CI)
```
