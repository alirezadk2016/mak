Afsluttende projekt for IT-supporter — Opgave 05. Opsætning af komplet netværksinfrastruktur for Cykelværkstedet CykelMyggen med 10 ansatte fordelt på 3 afdelinger.

10Brugere
3Afdelinger
2Servere
AKarakter

Tekniske krav

  • Domain Controller med AD/DS, DNS og DHCP — samt en dedikeret filserver
  • Filserver med sikret adgangskontrol — brugere kan kun tilgå egne mapper
  • Personligt drev pr. bruger, afdelingsdrev og fælles drev
  • Gruppepolitikker (GPO) til klientkonfiguration på tværs af afdelinger
  • pfSense firewall som sikkerhed til internetadgang
  • VLAN-segmentering til at adskille de tre netværksområder
  • Dynamisk routing-protokol mellem VLAN og internetadgang
  • PowerShell-automatisering af serverfunktioner
  • Redundant Domain Controller, DNS og DHCP (sekundær server)
  • Backup-løsning og lukning af ubrugte porte

Dokumentation

  • Netværkstopologi med IP-adresser, porte og hardware-roller
  • Komplet IP-adresseskema for hele netværket
  • Password-politik med kildedokumentation
  • Begrundelse for valg af hardware og software
  • Medarbejderskema over brugere og afdelinger
