IT-ordbog

De vigtigste begreber fra min hverdag som IT-supporter, forklaret uden teknisk jargon, og med eksempler på, hvordan jeg selv har brugt dem i praksis.

Netværk

DHCP

Dynamic Host Configuration Protocol

DHCP er den service, der automatisk giver hver enhed på et netværk en IP-adresse, så den kan kommunikere med andre.

Netværk

DNS

Domain Name System

DNS oversætter navne, mennesker kan huske (som yousee.dk), til IP-adresser, computere bruger.

Server

Active Directory

Microsoft Active Directory (AD)

Active Directory er Microsofts system til at styre brugere, computere og rettigheder centralt i en virksomhed.

Server

Windows Server

Windows Server er Microsofts styresystem til servere, de maskiner, der leverer services som login, filer, print og netværksstyring til alle virksomhedens computere..

Server

GPO

Group Policy Objects

GPO'er er regler, man sætter centralt i Active Directory, som automatisk gælder for brugere og computere.

Netværk

VLAN

Virtual Local Area Network

Et VLAN opdeler ét fysisk netværk i flere adskilte, logiske netværk.

Sikkerhed

VPN

Virtual Private Network

En VPN skaber en krypteret "tunnel" mellem din enhed og et andet netværk, fx virksomhedens.

Sikkerhed

Firewall

En firewall er netværkets dørmand: Den kigger på al trafik, der vil ind eller ud, og tillader kun det, reglerne siger god for.

Sikkerhed

Backup

Backup er en ekstra kopi af data, gemt et andet sted, så intet går tabt, hvis en disk dør, en fil slettes ved en fejl, eller virksomheden rammes af ransomware..

Server

Virtualisering

ESXi · VMware

Virtualisering lader én fysisk server køre mange "virtuelle" maskiner på samme tid.

Netværk

LAN & WLAN

Kablet og trådløst netværk

LAN er det kablede netværk i en bygning, computere forbundet via netværkskabler og switches.

Hardware

PC-hardware

Komponenter og fejlfinding

PC-hardware er computerens fysiske dele: CPU (hjernen), RAM (korttidshukommelsen), SSD (lageret), bundkort, strømforsyning og grafikkort.

Baseret på min uddannelse og praktiske erfaring.
